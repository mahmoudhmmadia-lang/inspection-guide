# الكشف على المنشآت خطوة بخطوة

دليل عربي للمبتدئ بفصل واحد: `chapters/01b-build.tex`. يبدأ بافتراض مؤسسة تريد تطبيق الكشف على المنشآت، ويشرح إعداد الفريق والبيانات والنموذج والربط والموافقة والتكليف، ثم عمل الباحث والمدقق، وإنشاء لوحة مؤشرات مرتبطة بالمنشآت والبحث والتصفية والنشر.

كل خطوة تشرح السبب، ثم جدولاً بحقول الشاشة (مطلوب أو موصى به أو اختياري، ومعنى كل خيار واختيار المثال)، ثم ما يضغطه القارئ وما يدخله، ثم النتيجة المطلوبة. يبدأ الفصل بخريطة العمل وطريقة القراءة وقاموس للكلمات. أُزيلت الفصول الجانبية من الموقع؛ مصادرها القديمة محفوظة فقط ولا تُبنى. شرح المؤشرات جزء من فصل التطبيق نفسه.

التفصيل مقصود في أدوات البناء: تصميم الحقول، وأقسام النموذج وأسئلته، والإلزام والقفل والتكرار والقواعد والقيم الافتراضية، وخريطة الربط، وقرارات المسار والصلاحيات، واختبارات الدورة، ثم مصادر المؤشرات وحسابها ورسومها ومرشحاتها وتشخيص أخطائها. يبقى إعداد الموارد البشرية مختصراً. تنتهي الخطوات بتطبيق للتحقق من الفهم؛ لا يشكل ذلك ادعاء بتغطية جميع قدرات المنصة أو إجراء الاختبارات الحية فعلياً.

## التشغيل

The guide bundles its renderer in `tools/` and theme in `web/`, copied from the shared guide sources. No sibling repositories are required. Update these bundled copies explicitly when adopting shared renderer/theme changes.

```powershell
npm run build
npm start
```

المعاينة: `http://127.0.0.1:4323/ar/`. ويمكن فتح `site/ar/c1.html` مباشرة.

## الصور والمصادر

تستخدم النسخة 14 صورة مرقّمة من منظمة المستخدم: الصور السبع الأصلية، وصورة `journey-check` المحفوظة سابقاً، وست صور جديدة: `org-question-settings` و`org-question-rules` و`org-required-condition` و`org-record-source` و`org-record-fields` و`org-dashboard-create`. مصدر الصور السابقة موثق في `review/capture/capture.mjs` (بيئة `org`)، ومصدر الصور الجديدة وتواريخها وروابطها في `review/capture/new-shots.json`. فُحصت الصور بصرياً وربطت أرقامها بإجراءات النص. صور المسار تعرض تحذيرات قبل اكتمال الإعداد، وصورة إنشاء اللوحة تعرض نافذة لم تُرسَل.

الأسماء والعلاقات موثقة في `review/organization-reference.json`. لا تتضمن النسخة صور `b-*` أو `i-*` من بيئة المثال السابق. يحذف البناء الصور غير المستخدمة من مجلد الموقع المولّد فقط.

خطوات اللوحة والبحث روجعت مقابل شيفرة محرر اللوحات. كانت قائمة اللوحات في المنظمة فارغة عند التصوير، لذلك التُقطت نافذة الإنشاء فقط. لم تُنشأ لوحة ولم تُنشر تغييرات. تصوير إعداد المؤشرات والرسوم والمرشحات ينتظر موافقة المستخدم على إنشاء مسودة غير منشورة. أداة التصوير تحظر طلبات الكتابة وتسمح بتسجيل الدخول والقراءات اللازمة فقط.

## التحقق

`npm test` يفحص بناء الفصل الوحيد والروابط والأسماء وشرح الخطوات والصور ومفاتيح أرقامها. نجحت الفحوص الستة.

نجح `npm run verify`: ثماني حالات عرض للرئيسية والفصل بعرضي 1440 و390 وبالمظهرين، مع فك ترميز الصور الأربع عشرة، وعدم تجاوز عرض الشاشة، والبحث وحفظ التقدم. التقرير في `review/browser-verification.json` وصور المعاينة في `review/screenshots/`. نجحت المعاينة محلياً عبر Playwright رغم عدم توفر مضيف التحكم المباشر. لم يُختبر سير اعتماد فعلي ولم تُغيّر بيانات المنظمة.

## Render deployment

Deploy this repository as a **Static Site**, branch `main`. Leave **Root Directory** empty, use **Build Command** `npm install && npm run build`, and set **Publish Directory** to `site` (not `.`). No start command is needed. Existing dashboard services must have these settings updated manually; `render.yaml` also defines them for Blueprint creation.

Local checks: `npm test`. For browser checks, run `npm --prefix tools ci`, then `npm run verify` (requires Microsoft Edge). Preview with `npm start`.

## الفصل الثاني: مثال من الواقع (دورية تموينية على فرن)

`chapters/02-real-example.tex` يطبّق أدوات الفصل الأول على عمل دوريات حماية المستهلك: جولة على أفران منطقة بخطة تكليف وإجابة مشتركة لعضوي الدورية، ومحضر فيه وزن الربطة أمام الزبون وبنود السعر والنظافة والدقيق، وأسئلة ضبط وعينة تظهر وتُطلب عند المخالفة فقط، وتدقيق رئيس الدائرة، وكتابة «الحالة الرقابية» و«تاريخ آخر دورية» في ملف الفرن عند الاعتماد، ثم متابعة التسوية أو الإحالة بلوحة مؤشرات. يضيف ثلاثة مناصب وأربعة أعضاء تجريبيين ودوراً واحداً، ويعيد استخدام منصب «رئيس دائرة حماية المستهلك».

الحقيقي فيه: عمل الدورية، ووزن الربطة أمام الزبون، وتسجيل الدقيق على البطاقة الإلكترونية، والضبط وفق المرسوم التشريعي 8 لعام 2021، وحجز العينة حتى نتيجة التحليل، والتسوية خلال سبعة أيام لبعض المخالفات ثم الإحالة إلى القضاء. لا يذكر وزناً معتمداً للربطة لأن المصادر تختلف؛ يُسجَّل من التعميم النافذ في كل محضر. الفصل بلا صور من النظام، وفيه رسم توضيحي واحد. لم تُنفذ هذه الدورة على منظمة حية بعد.
